## 5. 登录身份与接口

- 本项目**不是**官方应用，也未注册属于自己的开放平台应用身份。
- 登录流程使用的 OAuth 应用标识（`client_id=101444301`）**不属于本项目**。它来自一篇第三方公开帖，且据我们观察，它同时是某音乐 App 在应用市场的应用 ID，因此极可能是**官方 App 自身的应用身份**。
- 这意味着：该标识可能随时失效；用它登录会把请求记在该官方应用名下；**把它随软件分发可能涉及服务条款违约与身份冒用问题**。
- 接口形态来自公开 H5 资源的观察与本人账号的兼容性实验，不是官方文档，也不构成任何接口使用许可。

**因此：本项目不发布、也不建议任何人发布带有该标识的安装包或面向公众的分发版本。** 请仅以源码方式自行构建、自行使用。

## 6. 数据处理与隐私

- 音乐会话凭据仅保存在操作系统的凭据管理器（Windows Credential Manager / macOS Keychain），不写入项目目录、不提交、不上传。
- 播放队列、音量、播放模式等设置保存在本机应用数据目录的 `state.json`；歌词文本按曲目缓存 90 天，不含账号信息。
- 播放地址只作为当次播放结果使用，**不写日志、不写队列文件、不持久化**。
- 无遥测、无崩溃上报、无自动更新检查、无第三方统计。
- 日志不记录 URL 查询参数、请求体、原始响应、Authorization 头或完整曲目标识。
